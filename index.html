🌾El huerto — tu plato base
Comida real, panameña, sin sustitutos caros. Primero proteína + vegetales, después carbohidrato.
½ plato — vegetales (tomate, pepino, repollo, brócoli, espinaca, chayote…)
¼ plato — proteína (pollo, pescado, huevo, atún, sardinas, lentejas, frijoles)
¼ plato — carbohidrato (arroz, papa, yuca, ñame, plátano, avena)
+ un poco de grasa: aguacate, aceite de oliva, maní
🌅 Desayuno
  • 3 huevos + fruta + avena
  • 2 huevos + pollo/pavo + fruta
  • Avena + huevos + fruta
☀️ Almuerzo
  • Pollo/pescado/carne
  • Arroz, papa, yuca o ñame
  • Ensalada o vegetales
🌙 Cena
  • Pescado/pollo/carne/huevos
  • Muchos vegetales
  • Porción pequeña de carbohidrato
🧺 Cesta de emergencia (ADHD-proof)
  • 2–3 huevos + arroz + vegetales congelados
  • Atún + arroz + aguacate + tomate
  • Pollo rostizado + ensalada + papa
  • Sardinas + arroz + vegetales
  • Frijoles + huevo + arroz + ensalada
Meal prep: cocina base 2×/semana (domingo y miércoles): proteína + arroz/papa + vegetales, luego solo ensamblas.  ·  Hierro: combina lentejas/espinaca/carne roja con vitamina C (tomate, pimentón, naranja, limón); evita café/té junto a esas comidas.  ·  Insulina: caminar 10–15 min después de comidas grandes ayuda al control glucémico.
📖Recetario de la isla — porciones exactas
Cantidades pensadas para ~1550–1600 kcal/día repartidas en 3 comidas. Ajusta según hambre real; esto es un punto de partida, no una regla rígida.
📔Diario de crecimiento
Registra cada 2–4 semanas, en condiciones similares. La báscula sola no cuenta la historia: mira peso + cintura + grasa + músculo juntos.
